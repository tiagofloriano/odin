# Odin

Sistema de gerenciamento e criação de aplicações web, desenvolvido em PHP.

## Sobre o projeto

O Odin é um sistema que oferece uma base para autenticação, controle de acesso e gerenciamento de aplicações. Conta também com um editor de código e um *formbuilder* que permite visualizar, inserir e editar dados por meio de interfaces com layout padrão e opções de personalização via JavaScript.

O projeto está passando por uma reescrita para PHP 8, com foco na modernização do código, na segurança e na facilidade de manutenção e expansão.

## Objetivos

- Modernizar a estrutura do sistema para PHP 8;
- Implementar autenticação e gerenciamento de sessões de forma segura;
- Gerenciar usuários, pontos de acesso e grupos de menus;
- Facilitar a criação de interfaces e funcionalidades para novas aplicações;
- Manter uma estrutura simples, modular e extensível;
- Incentivar contribuições e o desenvolvimento colaborativo.

## Desenvolvimento

O desenvolvimento da nova versão ocorre na branch `php8`. A versão anterior está na branch `beta`.

### Branches

- `master`: versão estável (está vazia pois a versão anterior não saiu do beta)
- `beta`: versão anterior.
- `php8`: desenvolvimento da nova versão.

Novas funcionalidades e correções poderão ser desenvolvidas em branches próprias e submetidas por meio de Pull Requests.

## Tecnologias

- PHP 8
- Banco de dados MySQL
- HTML, CSS (Bootstrap) e JavaScript (jQuery)

As tecnologias e os requisitos definitivos serão documentados conforme a evolução do projeto.

## Contribuições

Contribuições são bem-vindas!

Antes de enviar alterações, recomenda-se:

1. Verificar as issues existentes ou discutir a proposta.
2. Criar uma branch específica para a funcionalidade ou correção.
3. Manter as alterações focadas e bem documentadas.
4. Testar o código antes de enviá-lo.
5. Abrir um Pull Request direcionado à branch `php8`.

Todas as contribuições estarão sujeitas à revisão antes de serem integradas ao projeto.
